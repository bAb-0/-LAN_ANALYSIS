# ÉLAN_ANALYSIS

## Sobre o Projeto
Este projeto tem como objetivo analisar os dados de vendas da loja **ÉLAN**, especializada em produtos de tecnologia.
A análise foi feita com base em dados simulados, utilizando o Power BI para construir um dashboard interativo e intuitivo.

## 🛠️ Ferramentas utilizadas
- Microsoft Excel (para organização dos dados)
- Power BI (para análise e visualização)

## 📈 Métricas e Análises Apresentadas
- **Quantidade de Produtos Vendidos**
- **Faturamento Geral** e **Ticket Médio**
- **Maior Venda Realizada**
- **Faturamento por Produto**
- **Faturamento por Região**
- **Faturamento por Mês**
- **Ranking de Vendedores por Quantidade e Faturamento**
